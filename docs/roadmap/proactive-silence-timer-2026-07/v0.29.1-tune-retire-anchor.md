# v0.29.1 — Tune the amplifiers + retire the old anchor

> **Status: PLANNED.** Initiative: Proactive silence-trigger redesign (Order 21, version 2/2).
> Risk: **Low**. Depends: v0.29.0. Flag: removes `LUNA_PROACTIVE_SILENCE_TIMER`.

## Goal

With the idle-timer proven in v0.29.0, make it the only path (delete the old user-only anchor) and
turn down the two secondary amplifiers that make Luna chatty even during genuine lulls: the ambient
threshold and the per-tick ambient probability. After this version the "静默" signal is both correct
(v0.29.0) and comfortably paced.

## What ships

**Retire the old anchor**
- `packages/server/src/proactive/ladder.ts` — delete the `LUNA_PROACTIVE_SILENCE_TIMER=0` branch; the
  `silenceGap`-from-`lastActivityMs` computation becomes unconditional. Remove the
  `silenceAnchorMs` selector.
- `packages/server/src/proactive/cadence.ts` / `fire.ts` — the anti-spam floor reads `lastActivityMs`
  unconditionally; drop the flag plumbing.
- `packages/server/src/turn/session.ts` — `lastUserMs` is retained (still the escalation-reset
  trigger); only the *silence-gap* consumers stop reading it.
- Grep-confirm `LUNA_PROACTIVE_SILENCE_TIMER` has zero remaining references.

**Tune the amplifiers (defaults only — all already env-resolved)**
- `packages/server/src/proactive/ladder.ts:64` — `LUNA_PROACTIVE_AMBIENT_MIN_MS` default
  **120_000 → 300_000** (a 5-minute lull, not 2, before a weightless ambient is even eligible).
- `packages/server/src/proactive/style.ts:59` — `LUNA_PROACTIVE_AMBIENT_PROB` default
  **0.12 → ~0.06** so the per-tick re-roll doesn't compound to near-certainty over a long silence.
- These are **default changes**, not new knobs; operators/tests can still override. `idleThresholdMs`
  (600s) and `nudgeProb` are left as-is — the ladder's escalation cadence is unchanged, only the
  ambient noise floor is lowered.

**No schema change, no new flag, no migration.**

## Tests

- **Old path gone** — the v0.29.0 flag-off test is deleted; a grep/test asserts no
  `LUNA_PROACTIVE_SILENCE_TIMER` reference remains.
- **Bounded ambient rate** — a simulated genuine 15-minute silence (deterministic `rng`) yields a
  cumulative ambient-fire probability under a target ceiling with the new defaults (documents the
  ~85% → comfortable-rate improvement as an assertion, not a claim).
- **Eligibility threshold** — an ambient is not offered until `silenceGap ≥ 300_000` under defaults.
- Existing `ladder.test.ts` / `cadence.test.ts` that pinned the old numeric defaults are updated to
  the new constants (search for `120_000` / `0.12` literals in the proactive tests).
- Full suite green; `tsc` clean.

## What this version explicitly does NOT include

- **No change to the ladder shape** — phases, renudge backoff, quota, dormant recovery, long-absence,
  and the user-keyed reset all stand exactly as Init 17 shipped them.
- **No new tuning surface** — only two existing defaults move.

## Risk

- **Low** — deleting an already-off fallback branch + changing two numeric defaults, both env-
  overridable. The behavior change (calmer ambient) is the intended product outcome.
- If the new ambient pacing feels *too* quiet in practice, both values are one-line default edits (or
  a live env override) — no code-shape dependency.

## Acceptance criteria

- [ ] `LUNA_PROACTIVE_SILENCE_TIMER` is fully removed; the idle-timer is the only silence path.
- [ ] Ambient defaults are 300_000 ms / ~0.06; overrides still honored.
- [ ] Cumulative ambient probability over a 15-minute silence is bounded under the documented ceiling.
- [ ] Full `bun test` green; `tsc` clean; `docs/history/DEVELOPMENT.md` updated for v0.29.0 + v0.29.1.

## Notes for the next initiative (don't foreclose)

- With silence now a single honest signal, a future "activeness"-aware pacing (Init 17's
  `set_proactive_style` already scales `ambientProb`/cooldown) could learn the ambient rate per user
  instead of a fixed default — the `lastActivityMs` timer is the clean substrate for that.
