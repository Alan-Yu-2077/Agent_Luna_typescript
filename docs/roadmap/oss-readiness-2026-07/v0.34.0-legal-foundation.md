## Goal
Give the repo a license so it can legally be forked/modified/contributed to, and attribute the two
redistributed third-party assets that MIT does not cover. Purely additive — the first, safest slice.

## What ships
- **`LICENSE`** (root): MIT, © the project, with an explicit **carve-out paragraph** excluding
  `packages/web/public/live2dcubismcore.min.js` (Live2D Cubism Core, Live2D Proprietary Software
  License, © Live2D Inc.) from the MIT grant.
- **`THIRD_PARTY_LICENSES`** (root): (a) Live2D Cubism Core — proprietary, kept under EULA, link +
  redistribution/revenue-cap note; (b) the three `packages/server/vendor/tree-sitter/*.wasm` blobs
  (all MIT) — upstream copyright + license text + version/source. **Do NOT** add a `yumi` model entry
  (the model is deleted in v0.34.6 — a bundle-attribution entry would go stale immediately).
- **`package.json` × 5** (root + `packages/{protocol,server,web,desktop}`): add `"license":"MIT"` +
  `"repository"` (**resolved: `https://github.com/Alan-Yu-2077/Luna-ts`**). **Keep `"private":true`** on the four
  workspace packages (they are not published to npm); re-evaluate root `private` when the URL lands.
