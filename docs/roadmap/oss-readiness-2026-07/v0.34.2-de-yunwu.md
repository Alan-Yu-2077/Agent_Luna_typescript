# v0.34.2 — De-yunwu (remove the private-gateway default)

> **Status: PLANNED.** Initiative: OSS Readiness (Order 3, version 3/9). Risk: **Medium** (onboarding
> test asserts the yunwu default). Depends: v0.34.0. Flag: none.

## Goal
Stop routing new users' API keys/traffic to the owner's private `yunwu.ai` proxy, and remove the
vendor name from source. The **highest-severity behavioral fix** in the initiative.

## What ships
- **The funnel** — `packages/web/src/ui/setupView.ts:55`: the API-base field's **default value AND
  placeholder** are `https://yunwu.ai`. Change the default to `https://api.anthropic.com` (or empty)
  and the placeholder to a neutral official endpoint. *(Live behavioral change — a click-through user
  now reaches Anthropic, not the owner's proxy.)*
- **Desktop error example** — `packages/desktop/src/onboarding.ts:59` (`classifyProbe` 404 branch):
  yunwu example → `api.anthropic.com` or drop it.
- **Comments → generic** — `provider/anthropic.ts:16`, `dream/prompts.ts:4`, `tools/builtin/remember.ts:8`,
  `tools/web/web_search.ts:12`: "yunwu" → "some OpenAI-compatible / proxy gateways" (keep the rationale).
- **Runtime coupling** — `dream/llm.ts:23` matches the Chinese overload string `饱和`; the generic
  429/overload matcher already covers public APIs → keep with a comment or drop the branch.
- **Scripts** — rename `scripts/smoke-yunwu.ts` → `smoke-gateway.ts` (+ header/run-example); fix the
  `ANTHROPIC_BASE_URL=https://yunwu.ai` run-banner comments in `proactive-soak.ts`,
  `ab-message-mode.ts`, `integrity-sweep.ts`.
- **`.env.example:7-8`** OpenAI-compat example → `api.openai.com/v1` / `<your-openai-compatible-gateway>/v1`.
- **Tests** — de-yunwu `runTurn.test.ts:235`, `jsonTextStream.test.ts:10`, `provider/anthropic.test.ts:4/7/12/17`,
  and **flip** `desktop/src/onboarding.test.ts:32/37` (asserts `ANTHROPIC_BASE_URL==='https://yunwu.ai'`)
  — change assertion + input env together.
